# 🧰 EF Core Interview Toolbox — Relationship Glossary

> **Quick-reference glossary for EF Core relationships**

---

# 🔑 Core Relationship Terms

| Term | Meaning |
|---|---|
| **Dependent Entity** | Entity that contains the **foreign key (FK)**. Also called the *child*. |
| **Principal Entity** | Entity that contains the **primary or alternate key** referenced by the FK. Also called the *parent*. |
| **Principal Key** | Property/properties that uniquely identify the principal entity. Can be a **primary key or alternate key**. |
| **Foreign Key** | Property/properties on the dependent that store values matching the principal key. |
| **Navigation** | Property that references the related entity or entities at the other end of a relationship. |
| **Collection Navigation** | Navigation containing multiple related entities. Used on the **many side** of one-to-many and many-to-many relationships. |
| **Reference Navigation** | Navigation pointing to a single related entity. Used on the **one side** of one-to-one and one-to-many relationships. |
| **Inverse Navigation** | The navigation at the **opposite end** of a relationship. |
| **Self-Referencing Relationship** | A relationship where the **principal and dependent entity types are the same**. |
| **Required Relationship** | Relationship with a **non-nullable FK**. The dependent cannot exist without a principal. |
| **Optional Relationship** | Relationship with a **nullable FK**. The dependent can exist without a principal. |
| **Bidirectional Relationship** | Relationship with navigations on **both sides**. |
| **Unidirectional Relationship** | Relationship with a navigation on **only one side**. |

# 🧠 Relationship Mental Model

```text
              PRINCIPAL
             (Parent)
                 │
          Principal Key
                 │
                 ▼
             DEPENDENT
             (Child)
                 │
          Foreign Key
                 │
                 ▼
            RELATIONSHIP
```

```text
NAVIGATIONS

Reference Navigation
        ↓
   One related Entity

Collection Navigation
        ↓
   Many related Entities
```

---

# 🔄 Required vs Optional

```text
Required
   ↓
Non-nullable FK
   ↓
Dependent MUST have Principal


Optional
   ↓
Nullable FK
   ↓
Dependent MAY have Principal
```

# ↔️ Navigation Direction

```text
Bidirectional

Principal ───→ Dependent
    ↑               │
    └───────────────┘


Unidirectional

Principal ───→ Dependent

        OR

Dependent ───→ Principal
```

# 🎯 Cardinality Reminder

```text
Reference + Reference
        ↓
     1 : 1

Collection + Reference
        ↓
     1 : N

Collection + Collection
        ↓
     M : N
```

> ⭐ **Quick memory:**  
> **Principal = Parent**  
> **Dependent = Child**  
> **Principal Key = Identity being referenced**  
> **Foreign Key = Reference stored by the dependent**  
> **Navigation = Object-oriented path to related data**
