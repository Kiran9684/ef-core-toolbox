This repository is designed for **quick EF Core revision and conceptual understanding**.

Each topic focuses on:

- 🧠 Mental models
- 🔄 Flow diagrams
- 👀 Visual representations
- 💡 Important concepts
- ⭐ Key rules and distinctions
- 💻 Essential code examples
- ⚡ 30-second revision summaries

> The goal is not to replace the official EF Core documentation, but to provide a **compact revision layer** for quickly recalling EF Core concepts.
